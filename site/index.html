Install the skill.

Run in your terminal. Choose your agent when prompted.

Terminal
npx skills add Makio64/gpu-perf-agent -g

One command for all supported agents. Installed across your projects via skills.

02

Ask your agent.

Start a new agent session in your project.

Your prompt
Use gpu-perf-agent to optimize the webgpu performance

Your agent runs the profiler, makes changes, and compares the results.

Requires Node.js 22+, Git, and Chrome / Chromium. Runs on your machine.

Under the hood

Give your agent a way to measure.

The skill teaches your agent to profile locally, investigate a bottleneck, and verify its code changes with repeatable measurements.

Profile your running app.

The CLI instruments your WebGPU or WebGL page in Chrome.

  • Frame pacing
  • Draw calls
  • Buffer & texture allocations

Optional Chrome traces add detail about browser activity.
